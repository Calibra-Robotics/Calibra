# Contributing to Calibra

**Open contributions. Evidence-gated merges.**

External pull requests are not open yet. We will open them once a Contributor
License Agreement is in place. Until then, bug reports, feature ideas and
dataset profile proposals are welcome as
[issues](https://github.com/Calibra-Robotics/Calibra/issues/new/choose).
Report security issues privately as described in [SECURITY.md](SECURITY.md),
not as public issues.

The standards every merged change must meet, and how dataset profiles are
evidenced, are in [docs/contributing.md](docs/contributing.md).
