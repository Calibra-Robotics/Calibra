# Contributing to Calibra

**Open contributions. Evidence-gated merges.**

Pull requests are welcome. Before your first one can be merged, sign the
[Contributor License Agreement](CLA.md): a bot comments on your pull request
with instructions, and you sign once by replying to it.

Not ready to write code? Bug reports, feature ideas and dataset profile
proposals are welcome as
[issues](https://github.com/Calibra-Robotics/Calibra/issues/new/choose), and
questions as [discussions](https://github.com/Calibra-Robotics/Calibra/discussions).
Report security issues privately as described in [SECURITY.md](SECURITY.md),
not as public issues.

The standards every merged change must meet, how dataset profiles are
evidenced, and the development setup are in
[docs/contributing.md](docs/contributing.md). How decisions are made is in
[GOVERNANCE.md](GOVERNANCE.md).
