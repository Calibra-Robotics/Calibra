# Security Policy

## Supported Versions

We actively support and patch security vulnerabilities in the following versions of Calibra:

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ Yes     |
| < Latest| ❌ No      |

We recommend always running the latest version available on PyPI (`calibra-robotics`).

## Reporting a Vulnerability

If you discover a security vulnerability in Calibra, please do not open a public GitHub issue. Instead, report it privately:

1. **Report privately:** Use GitHub's [private vulnerability reporting](https://github.com/Calibra-Robotics/Calibra/security/advisories/new). If you cannot use GitHub, email **omertahtoko@gmail.com** with "Calibra security" in the subject.
2. **Include details:** Provide steps to reproduce, a proof of concept (PoC), and potential impacts.
3. **Wait for response:** We will acknowledge your report within 48 hours and work on a security patch.
4. **Coordinated Disclosure:** We ask that you give us a reasonable timeframe (typically 30 to 90 days) to deploy a fix before disclosing it publicly.
